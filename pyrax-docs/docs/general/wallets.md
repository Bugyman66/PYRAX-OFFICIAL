# PYRAX Wallets

A cryptocurrency wallet is essential for storing, sending, and receiving PYRAX tokens. This guide covers your wallet options and how to set them up securely.

## What is a Crypto Wallet?

A crypto wallet doesn't actually "store" your tokens. Instead, it stores the private keys that prove you own tokens on the blockchain. Think of it like a password that gives you access to your funds.

### Key Concepts

| Term | Meaning |
|------|---------|
| **Public Address** | Your account number — share freely to receive funds |
| **Private Key** | Your password — NEVER share this |
| **Seed Phrase** | 12-24 words that can restore your wallet — backup safely |
| **Signing** | Approving transactions with your private key |

### Hardware Wallets (Cold Wallets)

Physical devices that store keys offline. Most secure option.

| Wallet | Price | Notes |
|--------|-------|-------|
| **Ledger Nano S Plus** | ~$79 | Popular, affordable |
| **Ledger Nano X** | ~$149 | Bluetooth, more storage |
| **Trezor Model One** | ~$69 | Open source |
| **Trezor Model T** | ~$219 | Touchscreen |

### Paper Wallets

Physical printout of keys. Secure if created safely, but inconvenient.

## Setting Up PYRAX Desktop

### Download
1. Visit [pyrax.org/downloads](https://pyrax.org/downloads)
2. Select your operating system
3. Download the installer
4. Verify the download (check hash if available)

### Installation
1. Run the installer
2. Follow installation prompts
3. Launch PYRAX Desktop

### Create New Wallet
1. Click "Create New Wallet"
2. Set a strong password
3. **Write down your seed phrase** (12 words)
4. Verify seed phrase by entering words
5. Wallet is ready!

### Import Existing Wallet
1. Click "Import Wallet"
2. Choose import method:
   - Seed phrase (12/24 words)
   - Private key
   - Keystore file
3. Enter your credentials
4. Set a password
5. Access your wallet

## Setting Up MetaMask

### Install Extension
1. Visit [metamask.io](https://metamask.io)
2. Click "Download"
3. Add extension to your browser
4. Click the MetaMask icon

### Create or Import Wallet
1. Follow setup wizard
2. Create new wallet OR import existing
3. **Backup your seed phrase securely**
4. Set a strong password

### Add PYRAX Network
1. Open MetaMask
2. Click network dropdown
3. Click "Add Network"
4. Enter PYRAX network details:

| Field | Value |
|-------|-------|
| Network Name | PYRAX Network |
| RPC URL | https://rpc.pyrax.org |
| Chain ID | *TBD at launch* |
| Currency Symbol | PYRAX |
| Block Explorer | https://explorer.pyrax.org |

5. Click "Save"

## Securing Your Wallet

### Seed Phrase Protection

Your seed phrase is the master key to your funds. If someone gets it, they can steal everything.

**DO:**
- ✅ Write it on paper (multiple copies)
- ✅ Store in secure locations (safe, safety deposit box)
- ✅ Consider metal backup (fireproof)
- ✅ Test recovery before adding significant funds

**DON'T:**
- ❌ Store digitally (computer, cloud, email)
- ❌ Take photos of it
- ❌ Share with anyone (ever)
- ❌ Enter on websites (except wallet recovery)

### Password Best Practices

- Use unique password for each wallet
- Minimum 12 characters
- Mix letters, numbers, symbols
- Consider a password manager

### Hardware Wallet Usage

For large amounts, use a hardware wallet:

1. **Purchase directly** from manufacturer (not Amazon/eBay)
2. **Verify seal** is intact on delivery
3. **Set up as new device** (never use pre-configured)
4. **Backup seed phrase** securely
5. **Test recovery** before sending funds

## Common Wallet Operations

### Receiving PYRAX

1. Open your wallet
2. Click "Receive" or copy your address
3. Share address with sender
4. Wait for transaction confirmation

**Tip**: Always double-check addresses. Transactions can't be reversed.

### Sending PYRAX

1. Open your wallet
2. Click "Send"
3. Enter recipient address
4. Enter amount
5. Review transaction fee
6. Confirm and send

**Tip**: Send a small test transaction first when using new addresses.

### Checking Balance

- Open PYRAX Desktop dashboard
- Or view on block explorer using your address
- MetaMask shows balance if network is added

## Troubleshooting

### Wallet Not Syncing
- Check internet connection
- Restart the application
- Wait — initial sync takes time

### Transaction Pending
- Check network congestion
- May need to wait or increase gas
- Check transaction on block explorer

### Lost Password
- Cannot be recovered
- Use seed phrase to restore in new wallet
- Set new password during restoration

### Lost Seed Phrase
- Funds may be permanently lost
- If wallet is still accessible, transfer to new wallet immediately
- Create new wallet and backup properly

## Frequently Asked Questions

### Can I use multiple wallets?
Yes. Many users have a "hot" wallet for daily use and "cold" wallet for savings.

### Is PYRAX Desktop safe?
Yes, it's the official wallet. Download only from pyrax.org.

### What if my computer breaks?
Use your seed phrase to restore wallet on any device.

### Can I use the same wallet for mining and trading?
Yes, one wallet works for all PYRAX activities.

### How do I backup my wallet?
Backup = securing your seed phrase. The wallet itself can be restored from the seed phrase.
