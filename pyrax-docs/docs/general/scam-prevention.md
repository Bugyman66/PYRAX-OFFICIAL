# Scam Prevention

Cryptocurrency scams are unfortunately common. This guide helps you identify and avoid scams targeting PYRAX users.

## Common Scam Types

### 1. Fake Support Scams

**How it works:**
- Scammer monitors Discord/Telegram for people asking for help
- Contacts victim via DM pretending to be "PYRAX Support"
- Asks for seed phrase, private keys, or remote access
- Steals all funds

**Red flags:**
- Unsolicited DM from "support"
- Requests for private keys or seed phrase
- Asks to connect to a "support tool" or website
- Creates urgency about your wallet being "at risk"

**Protection:**
- Official support NEVER DMs first
- NEVER share seed phrase or private keys
- Ask questions in public channels only
- Verify staff by checking roles in official Discord

### 2. Giveaway/Airdrop Scams

**How it works:**
- Fake accounts promise "PYRAX giveaway" or "double your coins"
- Often impersonate team members or influencers
- Require you to send crypto first
- Disappear with your funds

**Red flags:**
- "Send X PYRAX, receive 2X back"
- Requires sending crypto to participate
- Posted by accounts with few followers
- Links to suspicious websites

**Protection:**
- Real airdrops NEVER require sending crypto
- Verify announcements on official channels
- If it seems too good to be true, it is
- Report and block fake accounts

### 3. Phishing Websites

**How it works:**
- Creates fake websites that look like official PYRAX sites
- Tricks you into entering seed phrase or connecting wallet
- Drains your wallet through malicious contracts

**Red flags:**
- URLs that are slightly misspelled (pyrax-io.com, pyraxx.org)
- Sites asking for seed phrase
- Pop-ups requesting wallet connection
- Links from unsolicited messages

**Protection:**
- Bookmark official sites and only use bookmarks
- Type URLs directly
- Check for HTTPS and correct domain
- Never enter seed phrase on any website

### 4. Impersonation Scams

**How it works:**
- Creates accounts that look like team members
- Same name, similar profile picture
- Contacts victims with "special opportunities"

**Red flags:**
- Account created recently
- Slight differences in username (@pyrax_official vs @pyrax_0fficial)
- DMs about investment opportunities
- Asks for personal information

**Protection:**
- Check account creation date and history
- Verify through official channels
- Team members don't DM about investments
- Report impersonators

### 5. Fake Token Scams

**How it works:**
- Creates tokens with similar names (PYRAX2, PYRAXClassic)
- Lists on DEXs to trick buyers
- Token has no value or is rug-pulled

**Red flags:**
- Token address doesn't match official
- Listed only on unknown DEXs
- Different from official contract

**Protection:**
- ALWAYS verify contract addresses from official sources
- Check [pyrax.org](https://pyrax.org) for official contract
- Don't buy tokens from unknown sources

### 6. Pump and Dump Schemes

**How it works:**
- Group coordinates to buy, hype, then sell
- Victims buy during the hype
- Organizers dump, price crashes
- Victims left with losses

**Red flags:**
- "Insider tips" about price movement
- Coordinated social media campaigns
- Promises of guaranteed profits
- Pressure to buy immediately

**Protection:**
- Do your own research
- Be skeptical of hype
- Don't FOMO into sudden pumps
- Invest based on fundamentals

### 7. Malware and Keyloggers

**How it works:**
- Downloads disguised as mining software or wallets
- Steals private keys or seeds
- Monitors clipboard to replace addresses

**Red flags:**
- Downloads from unofficial sources
- Software asking for seed phrase
- Wallet addresses changing when copied

**Protection:**
- Only download from official sources
- Verify file hashes when possible
- Use antivirus software
- Check pasted addresses match copied

## How to Verify

### Verify Team Members
1. Check official Discord server
2. Look for official roles
3. Ask publicly before trusting DMs
4. Staff will respond in public channels

### Verify Announcements
1. Check multiple official channels
2. Look for consistent messaging
3. Announcements are never DM-only
4. When in doubt, ask in Discord

### Verify Contract Addresses
1. Check official website
2. Verify on official announcements
3. Cross-reference multiple sources
4. Use block explorer to verify

## What To Do If Scammed

### Immediate Actions
1. **Move remaining funds** to new wallet with fresh seed
2. **Revoke approvals** on compromised wallet
3. **Document everything** (screenshots, transaction hashes)
4. **Change all passwords** starting with email

### Report the Scam
1. Report to PYRAX Discord moderators
2. Report accounts to platform (Twitter, Discord, etc.)
3. Report phishing sites to Google Safe Browsing
4. File report with local authorities if significant loss

### Warn Others
- Share experience in community (without personal details)
- Help identify scam patterns
- Protect others from same scam
