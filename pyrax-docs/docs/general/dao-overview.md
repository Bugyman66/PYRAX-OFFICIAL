# DAO Overview

The PYRAX DAO (Decentralized Autonomous Organization) gives token holders the power to govern the network. This guide explains how the DAO works and how you can participate.

## What is a DAO?

A DAO is an organization run by rules encoded in smart contracts, where decisions are made by member votes rather than a central authority.

**Traditional Organization:**
- Executives make decisions
- Limited transparency
- Slow to change
- Members have little say

**DAO:**
- Token holders vote on decisions
- All proposals and votes are public
- Can adapt quickly
- Democratic participation

## PYRAX DAO Structure

### Governance Token

PYRAX tokens serve as both utility and governance tokens:
- 1 PYRAX = 1 vote (base)
- Staked PYRAX = bonus voting power
- Long-term stakers = higher influence

### Voting Power Multipliers

| Staking Duration | Voting Multiplier |
|------------------|-------------------|
| Unstaked | 1.0x |
| 30-day stake | 1.1x |
| 90-day stake | 1.25x |
| 365-day stake | 1.5x |

**Example:**
- 10,000 PYRAX unstaked = 10,000 votes
- 10,000 PYRAX in 365-day stake = 15,000 votes

## Governance Process

### Proposal Lifecycle

```
┌─────────┐    ┌──────────┐    ┌─────────┐    ┌──────────┐
│ Draft   │───►│ Discussion│───►│ Voting  │───►│ Execution│
└─────────┘    └──────────┘    └─────────┘    └──────────┘
   1-2 days      5-7 days        7 days        Immediate
```

### 1. Draft Phase (1-2 days)
- Author creates detailed proposal
- Includes rationale, specifications, timeline
- Posted for initial feedback

### 2. Discussion Phase (5-7 days)
- Community discusses in forum and Discord
- Author may revise based on feedback
- Build support before voting

### 3. Voting Phase (7 days)
- Proposal goes to on-chain vote
- Token holders cast votes
- Requires quorum and majority

### 4. Execution Phase
- Passed proposals executed automatically
- Or queued for implementation
- Results published on-chain

## Participation Guide

### Voting on Proposals

**Requirements:**
- PYRAX tokens (more = more votes)
- Connected wallet
- Gas for vote transaction (minimal)

**Steps:**
1. Visit [dao.pyrax.org](https://dao.pyrax.org)
2. Connect your wallet
3. Browse active proposals
4. Review details and discussion
5. Cast your vote (For/Against/Abstain)
6. Confirm transaction

### Creating Proposals

**Requirements:**
- Minimum 100,000 PYRAX (proposal threshold)
- Clear specification
- Community support

**Proposal Template:**
```markdown
# Proposal Title

## Summary
Brief description of what this proposal does.

## Motivation
Why is this change needed?

## Specification
Technical details of implementation.

## Benefits
What improvements does this bring?

## Risks
Potential downsides and mitigations.

## Timeline
Implementation schedule.
```

### Delegating Votes

If you can't actively participate, delegate your voting power:
1. Go to DAO dashboard
2. Click "Delegate"
3. Enter delegate's address
4. Confirm transaction

Your tokens stay in your wallet; only voting power is delegated.

## Proposal Types

### Standard Proposals
- 7-day voting period
- Requires 4% quorum
- Simple majority to pass

### Constitutional Proposals
For major protocol changes:
- 14-day voting period
- Requires 10% quorum
- 66% supermajority required

### Emergency Proposals
For urgent security issues:
- 48-hour voting period
- Requires 5% quorum
- 75% supermajority required
- Limited scope (security only)

## Best Practices

### For Voters
1. **Read full proposals** — Don't vote on titles alone
2. **Understand implications** — Consider long-term effects
3. **Participate in discussion** — Share concerns before voting
4. **Vote consistently** — Build voting reputation

### For Proposal Authors
1. **Build support first** — Discuss before proposing
2. **Be specific** — Vague proposals fail
3. **Consider opposition** — Address concerns proactively
4. **Communicate actively** — Respond to questions
