# Security Best Practices

Protecting your PYRAX tokens and personal information is crucial. This guide covers essential security practices for all users.

## Wallet Security

### Seed Phrase Protection

Your seed phrase (12 or 24 words) is the master key to your funds.

**DO:**
- ✅ Write it on paper (multiple copies)
- ✅ Store in secure locations (safe, safety deposit box)
- ✅ Consider metal backup plates (fireproof, waterproof)
- ✅ Test recovery before adding significant funds
- ✅ Keep copies in geographically separate locations

**DON'T:**
- ❌ Store digitally (computer, phone, cloud)
- ❌ Take photos or screenshots
- ❌ Email or message to anyone
- ❌ Enter on any website except wallet recovery
- ❌ Share with anyone, ever, for any reason

:::danger Critical Warning
No legitimate person will EVER ask for your seed phrase. Anyone who does is a scammer. PYRAX team, support, moderators — none will ever need it.
:::

### Password Security

- Use unique passwords for each crypto service
- Minimum 16 characters recommended
- Mix uppercase, lowercase, numbers, symbols
- Use a reputable password manager
- Never reuse passwords from other sites

### Two-Factor Authentication (2FA)

Enable 2FA on all crypto accounts:
- Use authenticator apps (Google Authenticator, Authy)
- Avoid SMS 2FA when possible (SIM swap risk)
- Backup 2FA recovery codes securely
- Never share 2FA codes with anyone

## Hardware Security

### Hardware Wallets

For significant holdings, use hardware wallets:
- Ledger Nano S/X
- Trezor Model One/T

**Best practices:**
- Buy directly from manufacturer only
- Verify package seal is intact
- Set up as new device (never pre-configured)
- Store securely when not in use

### Computer Security

- Keep operating system updated
- Use reputable antivirus software
- Don't install unknown software
- Avoid pirated software (malware risk)
- Use a dedicated computer for crypto (if possible)

### Mobile Security

- Keep phone OS updated
- Use device encryption
- Set strong lock screen
- Be cautious with app permissions
- Don't jailbreak/root devices with crypto apps

## Online Security

### Phishing Prevention

Phishing is the #1 way people lose crypto.

**Red flags:**
- Unexpected DMs about crypto opportunities
- Urgency ("Act now or lose funds!")
- Requests for private information
- Links that look slightly wrong
- Poor grammar/spelling

**Protection:**
- Bookmark official sites
- Type URLs directly
- Verify SSL certificates
- Never click links in unsolicited messages
- When in doubt, ask in official Discord

### Social Media Safety

- Be skeptical of DMs from strangers
- Ignore "giveaway" or "airdrop" offers
- Don't share portfolio size publicly
- Verify accounts are official
- Report impersonators

### Email Security

- Use dedicated email for crypto
- Enable 2FA on email accounts
- Be suspicious of attachments
- Verify sender addresses carefully
- Don't click links in unexpected emails

## Transaction Security

### Before Sending

1. **Triple-check addresses** — Crypto transactions are irreversible
2. **Send test transaction first** — Small amount before large transfers
3. **Verify contract addresses** — When interacting with DEXs
4. **Check network** — Ensure correct blockchain

### Address Verification

- Copy-paste addresses (don't type manually)
- Verify first and last several characters
- Use address book for frequent recipients
- Watch for clipboard malware

### Contract Interactions

Before signing transactions:
- Read what you're approving
- Check spending limits
- Understand what the contract can do
- Verify contract on block explorer

## Exchange Security

### Choosing Exchanges

- Use reputable, established exchanges
- Check security track record
- Verify regulatory compliance
- Read reviews and research

### Account Protection

- Strong unique password
- 2FA enabled (authenticator app)
- Withdrawal address whitelist
- Email notifications for activity
- API key restrictions (if using APIs)

### Funds Management

- Don't store large amounts on exchanges
- Withdraw to personal wallet regularly
- "Not your keys, not your coins"
- Only keep trading amounts on exchange

## Mining Security

### Software Safety

- Download miners from official sources only
- Verify file hashes when available
- Add miner to antivirus exclusions carefully
- Keep mining software updated

### Remote Access

If mining remotely:
- Use VPN for connections
- Strong authentication
- Limited access permissions
- Monitor for unauthorized access

## Recognizing Scams

### Common Scam Types

| Scam | Description |
|------|-------------|
| **Fake support** | Impersonates support, asks for funds/keys |
| **Giveaway scams** | "Send 1 ETH, get 2 back" — always fake |
| **Impersonation** | Fake accounts of team/influencers |
| **Pump and dump** | Coordinated price manipulation |
| **Rug pulls** | Project disappears with funds |
| **Phishing sites** | Fake sites that steal credentials |

### Protection Strategies

1. **If it's too good to be true, it's a scam**
2. **Legitimate projects never DM first**
3. **Real airdrops don't require sending crypto**
4. **Verify everything independently**
5. **Take your time — scammers create urgency**

## Recovery Planning

### What to Backup

- Seed phrases (secure physical copies)
- 2FA recovery codes
- Password manager backup
- List of accounts and wallets

### If Compromised

1. **Move funds immediately** to new wallet with fresh seed
2. **Change all passwords** starting with email
3. **Revoke token approvals** on compromised wallet
4. **Report to community** to warn others
5. **Document everything** for potential law enforcement

### Estate Planning

Consider:
- How will heirs access your crypto?
- Secure instructions for trusted family
- Legal documentation if significant value
